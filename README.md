# Ireng

Discord community bot for the ADIP RMX server — moderation, conversational AI, and a live dashboard. Designed and built entirely from a phone.

> The source code is private. This repo is the public information page.

## What it does

- **Moderation that runs itself** — automated filters for spam, gambling content, and misplaced promo links. Staff get alerts; the bot doesn't hand out blind punishments.
- **A brain, not a chatbot** — a fully scripted conversational engine (50,000+ intents and counting) with neural embeddings running locally on its own hardware. No external AI API calls, ever.
- **Learns every day** — scheduled knowledge-mining pipelines draft new understanding daily. Nothing goes live without passing review gates.
- **Private rooms** — every member gets their own private channel where Ireng holds real conversations, remembers context, and matches their tone.
- **Proactive, politely** — video notifications, level-ups, and reminders with cooldowns and quiet hours. It knows when to stay silent.
- **Live dashboard** — real-time stats, health, and knowledge queues behind a private login.

## By the numbers

- 50,732 intents (October 2026)
- 24/7 uptime with automatic crash recovery
- Built phone-only — no laptop, no desktop
